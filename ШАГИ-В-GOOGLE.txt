ШАГИ В GOOGLE — подключение приёмника заявок «Теремок»
Почта приёмника: teremok.zayavki@gmail.com
Код приёмника: C:\Users\Андрей\Desktop\teremok\скрипт-для-google.txt

Шаг 0. Откройте браузер, убедитесь, что вошли ИМЕННО как teremok.zayavki@gmail.com
        (кружочек профиля справа вверху показывает почту).

Шаг 1. В адресной строке наберите: sheets.google.com
        Нажмите «Пустой файл» (плюсик). Создастся таблица.

Шаг 2. Сверху слева щёлкните «Новая таблица» и переименуйте в: Теремок — заявки

Шаг 3. Меню таблицы: Расширения -> Apps Script.
       Откроется редактор кода. Удалите из него весь текст.

Шаг 4. Откройте файл скрипт-для-google.txt (двойной клик — Блокнот).
       Ctrl+A (выделить всё), Ctrl+C (копировать).
       В редакторе Google: Ctrl+A, Ctrl+V (вставить вместо старого).

Шаг 5. Значок дискеты (Сохранить). Имя проекта: Приём заявок (или любое).

Шаг 6. Справа вверху: Развернуть -> Новая развёртка.
       Шестерёнка «Тип развёртывания» -> Веб-приложение.
       «Выполнять как»: я (ваша почта).
       «Кому доступно»: Все.
       Нажмите «Развернуть».

Шаг 7. Google попросит доступ: «Авторизоваться» -> выбрать аккаунт ->
       жёлтый экран «Google не проверил это приложение» (ЭТО НОРМАЛЬНО,
       приложение ваше собственное) -> «Дополнительные настройки» ->
       «Перейти на страницу... (небезопасно)» -> «Разрешить».

Шаг 8. Появится «URL веб-приложения» — длинная ссылка вида:
       https://script.google.com/macros/s/AKfycb.../exec
       Скопируйте её и пришлите в чат RUFP.

ДАЛЬШЕ ВСЁ ДЕЛАЕТ АССИСТЕНТ:
  - проверит приёмник тестовой заявкой (в таблице появится строка,
    на почту придёт письмо «ЗАЯВКА № ...»);
  - впишет URL в config.js (строка bookingScriptUrl);
  - опубликует сайт на GitHub Pages и проверит живую форму.

ПРИМЕЧАНИЯ
  - Номера заявок: 11-01, 11-02... Первые цифры — месяц. В декабре сами
    начнутся с 12-01. Обнуление ежемесячное, вручную ничего делать не надо.
  - Если захотите поменять код приёмника позже: после правки кода в Apps Script
    нужно Развернуть -> Управление развертываниями -> карандаш -> Версия: Новая ->
    Развернуть. Иначе сайт продолжит работать со старой версией.
